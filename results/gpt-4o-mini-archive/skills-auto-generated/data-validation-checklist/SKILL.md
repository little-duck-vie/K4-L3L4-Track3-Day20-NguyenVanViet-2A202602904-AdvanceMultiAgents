---
name: data-validation-checklist
description: Use whenever you are processing or analyzing structured data to ensure output integrity and compliance with specifications.
---
1. Verify that all required input files exist before processing.
2. Ensure output files are created with the correct schema and data types as specified.
3. Validate that all output data adheres to the required formats (e.g., date formats, currency in cents).
4. Remove any duplicate rows from the output data and ensure distinct entries are maintained.
5. Confirm that the output files are written to the correct locations as specified in the requirements.
6. Run validation checks on the output data to ensure it meets all specified criteria before claiming completion.
